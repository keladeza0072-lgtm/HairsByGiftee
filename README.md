# HairsByGiftee

A warm, editorial wig storefront with a deliberately simple owner dashboard and WhatsApp ordering.

## Preview

- Storefront: `/`
- Owner dashboard: `/admin/`

The current prototype uses browser localStorage so the owner can test Products, Hot Deals, Announcements and Reviews before Firebase persistence/authentication is wired in.
